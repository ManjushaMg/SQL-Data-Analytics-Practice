DDL Commands and constraints 
Employee database schema
This assignment uses DDL commands and constraints to analyse the employee database schema
Tools used:MYSql 

Steps followed

1.Table creation(CREATE)
2.Table alteration(ALTER)
3.Renaming table(Rename)
4.Table truncation(Truncate)
5.Table dropping(Drop)
6.Table Relationship creation(joined department table and employees table by assigning department id as foreign key and similarly joined employees table and location table by assigning location id as foreignkey)
7.Used constraints to make the dataset into a desired format
